# Generated app-server protocol types

Generated by codex-cli **0.160.0** — do not edit by hand, except for the import-specifier rewrite below
(NodeNext needs explicit `.ts` extensions). Excluded from Biome (root `biome.json`); typechecked with the rest
of the engine.

Regenerate (from the repo root) after upgrading codex:

```sh
rm -rf src/engine/codex/protocol/{*.ts,v2,serde_json}
codex app-server generate-ts --experimental --out src/engine/codex/protocol </dev/null
find src/engine/codex/protocol -name '*.ts' -exec sed -E -i '' \
  's#(from "\.{1,2}/[^"]+)"#\1.ts"#; s#"\./v2\.ts"#"./v2/index.ts"#' {} +
pnpm typecheck && pnpm test
```

(`sed -i ''` is BSD sed; on Linux use `sed -i`.) Then update the version above and the fixtures in
`../fixtures/` if the wire format changed. Adapter code imports only what it needs (see `../methods.ts`).
